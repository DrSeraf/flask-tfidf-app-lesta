# flask-tfidf-app-lesta

**Репозиторий для тестового задания в Lesta Games**

---

## 🚀 Описание проекта

Это приложение анализирует текстовые файлы с помощью алгоритма **TF-IDF** (Term Frequency-Inverse Document Frequency). Такой подход позволяет определить значимость каждого слова в документе относительно всего корпуса текстов.

---

## ✨ Дополнительные возможности и улучшения

- **Удаление стоп-слов:**  
  Автоматическая фильтрация распространённых русских стоп-слов с помощью библиотеки [NLTK](https://www.nltk.org/).

- **Предобработка текста:**  
  Текст очищается от пунктуации, приводится к нижнему регистру и разбивается на слова для повышения качества анализа.

- **Сортировка по убыванию IDF:**  
  Таблица результатов автоматически сортируется по убыванию значения IDF - самые значимые слова отображаются первыми.

- **Постраничный вывод:**  
  Если в результате анализа найдено более 15 слов, таблица автоматически разбивается на страницы с удобной навигацией.

- **Визуализация результатов:**  
  Для загруженного текста строится облако слов по частоте, а также отображается график (bar chart) топ-10 слов по TF.

- **Скачивание результатов:**  
  Результаты анализа можно скачать в формате CSV одним кликом.

- **Интерактивный фильтр:**  
  Над таблицей есть поля для фильтрации по слову, минимальному TF и минимальному IDF - фильтрация происходит прямо в браузере без перезагрузки страницы.

- **Ограничение размера файла:**  
  Максимальный размер загружаемого файла - **2 МБ**.

- **Автоматическое создание папки для загрузок:**  
  При первом запуске создаётся папка для хранения загруженных файлов.

- **Валидация формата файла:**  
  Поддерживаются только текстовые файлы с расширением `.txt`.

- **Обработка ошибок:**  
  Пользователь получает информативные сообщения при ошибках загрузки или анализа файлов.

## 📋 Пример использования

1. **Загрузите** текстовый файл (`.txt`) размером до 2 МБ.
2. **Дождитесь обработки**: текст будет очищен и проанализирован.
3. **Получите результат**:
   - Таблица слов, отсортированная по убыванию IDF (с пагинацией, если слов больше 15).
   - Облако слов и график топ-10 по TF.
   - Возможность фильтровать таблицу по слову, TF и IDF.
   - Возможность скачать результаты в формате CSV.

## ℹ️ О TF-IDF

> **TF-IDF (Term Frequency-Inverse Document Frequency)** - это статистическая мера, используемая для оценки важности слова в контексте документа или корпуса. Она помогает выделить ключевые слова, которые наиболее важны для конкретного текста, учитывая их частоту и уникальность среди других документов.
