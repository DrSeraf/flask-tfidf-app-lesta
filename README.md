# flask-tfidf-app-lesta
The repository for the test task in Lesta Games

Дополнительные возможности и улучшения
В рамках выполнения тестового задания я реализовал ряд улучшений, которые делают работу приложения более удобной и современной:
Удаление стоп-слов:
Для повышения качества анализа и релевантности результатов реализована автоматическая фильтрация распространённых русских стоп-слов с помощью библиотеки NLTK.
Предобработка текста:
Перед анализом текст автоматически очищается от пунктуации, приводится к нижнему регистру и разбивается на слова, что позволяет избежать дублирования.
Сортировка по убыванию IDF:
Выводимая таблица автоматически сортируется по убыванию значения IDF.
Ограничение размера загружаемого файла:
Для защиты приложения реализовано ограничение максимального размера загружаемого файла (2 МБ).
Автоматическое создание папки для загрузок:
При первом запуске приложение автоматически создаёт папку для хранения загруженных файлов, что упрощает развёртывание.
Валидация формата файла:
Приложение принимает только текстовые файлы с расширением .txt, что исключает ошибки при загрузке неподдерживаемых форматов.
Обработка ошибок:
Реализована обработка типовых ошибок загрузки и анализа файлов с информативными сообщениями для пользователя.
