## Описание проекта

Это веб-приложение для анализа текстовых файлов с помощью алгоритма TF-IDF (Term Frequency-Inverse Document Frequency). Приложение позволяет загружать текстовые файлы, анализировать их и визуализировать результаты в виде таблиц, облаков слов и графиков.

## ✨ Особенности

- Анализ текста с помощью алгоритма TF-IDF
- Удаление стоп-слов (русский язык)
- Предобработка текста (очистка от пунктуации, приведение к нижнему регистру)
- Сортировка результатов по убыванию IDF
- Постраничный вывод результатов
- Визуализация:
  - Облако слов
  - График топ-10 слов по TF
- Скачивание результатов в формате CSV
- Фильтрация результатов прямо в браузере
- Ограничение размера загружаемого файла (2 МБ)
- Автоматическое создание папки для загрузок
- Валидация формата файла (только .txt)

## 🚀 Запуск приложения

### Локальный запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt

bash
python app.py
Приложение будет доступно по адресу: http://localhost:5000

Соберите образ:
bash

🌐 API Endpoints

GET /status

Возвращает статус приложения:

json
{"status": "OK"}
GET /metrics

Возвращает метрики приложения:

json
{
  "uploaded_files_count": 0,
  "processed_words_total": 0,
  "average_processing_time_ms": 0
}
uploaded_files_count - общее количество обработанных файлов
processed_words_total - общее количество обработанных слов
average_processing_time_ms - среднее время обработки файла (мс)
GET /version

Возвращает версию приложения:

json
{"version": "1.1.0"}

📊 О TF-IDF

TF-IDF (Term Frequency-Inverse Document Frequency) - статистическая мера для оценки важности слова в контексте документа или корпуса. Помогает выделить ключевые слова, учитывая их частоту и уникальность.

Формула:

TF-IDF = TF * IDF
Где:

TF (Term Frequency) - частота термина в документе
IDF (Inverse Document Frequency) - обратная частота документа:
log(общее число документов / количество документов с термином)
